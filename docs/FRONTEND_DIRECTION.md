# Apprentice redesign direction

Subject inventory: one expert take; a second held-out take; four colored tubes; blue cap; dropper; geometric masks; false-to-true predicates; the exact missing-cap moment; a protocol with action history; unknown observations; a saved evidence chain; personal run records.

Argument:
- The product makes a physical demonstration inspectable -> one deliberate tabletop image, not a dashboard dumped into a hero.
- Omissions become visible -> working clean-versus-skipped comparison backed by the existing synthetic engine outputs.
- Learning, observing, and keeping evidence form one workflow -> actual interface fragments in a single colored band.
- An audit is only useful if its claims are honest -> exact event + predicate + provenance, and current model limitations.
- Start with a real working replay -> workspace action, no fake waitlist or pricing.

Dealt direction: One motif, seed 1643139742. Jost; cobalt on sand (#062b8a / #e6dbc7), softer surface #ddd0b9. The circular top of Apprentice's blue sample tube becomes the image window and the crop used throughout the homepage. The physical object, rather than ornamental SaaS chrome, supplies the visual motif.

Live thing: toggle Clean run / Skipped cap to change real synthetic protocol results, then inspect that exact run in the workspace. Homepage illustrations are labelled illustrative; no real model accuracy is implied.

Workspace: separate app shell with a slim sidebar, smaller task heading, large evidence canvas, legible four-step review, saved run library, private account controls. White and cool gray app surfaces; blue is action/selection, coral is deviation. No oversized marketing headline inside the tool.

Backend: isolated Supabase project, email/password authentication, private owner-scoped protocols/runs/recordings, storage policies, persistent run library and staged recording uploads. A guest can always use replay. Local Python inference remains the existing engine; Meta API keys/recordings are still deferred. Supabase does not pretend to run the Python video engine.

Hero copy: Good work. / Worth repeating.
Supporting copy: Turn a demonstration into a procedure you can inspect. Catch the moment a later run goes off course.
Primary action: Try the workstation.
Homepage sections: See the difference. / A procedure, with a memory. / Follow the evidence. / Your next run starts here.
